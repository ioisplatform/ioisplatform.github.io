# IOIS Student Learning Platform (7 Plans)

> भारत का अपना संपूर्ण डिजिटल छात्र अध्ययन एवं कौशल मंच (कक्षा 1 से 12 एवं कोडिंग/करियर स्किल्स)

## 🌟 विशेषताएं (Features)

1. **📚 7 संपूर्ण अध्ययन योजनाएं (Class 1-12 & Skills):**
   - **Plan 01: बाल विकास एक्सेस (NCERT Class 1-5 Foundation)** - स्वर, व्यंजन, 1-100 गिनती, पहाड़ा, अंग्रेजी फोनिक्स व दैनिक EVS
   - **Plan 02: यूथ स्किल स्टार्टर (Class 6-8 + AI)** - कंप्यूटर बेसिक्स, टाइपिंग, फाइल मैनेजमेंट व एआई टूल्स
   - **Plan 03: करियर फाउंडेशन (Class 9-10)** - स्पोकन इंग्लिश, 1 मिनट सेल्फ-इंट्रोडक्शन, पर्सनालिटी डेवलपमेंट
   - **Plan 04: फैमिली व छात्र बेसिक (Class 11-12)** - व्यावहारिक गणित, घरेलू हिसाब, सामान्य विज्ञान व स्वास्थ्य
   - **Plan 05: स्टूडेंट एलीट पास (Board Exam Prep)** - 10वीं/12वीं बोर्ड परीक्षा मॉडल पेपर्स, फॉर्मूला शीट्स व टिप्स
   - **Plan 06: डिजिटल स्किल व कोडिंग** - कंप्यूटर प्रोग्रामिंग, वेब बेसिक्स, सरकारी ऑनलाइन फॉर्म्स व प्रोजेक्ट्स
   - **Plan 07: सुप्रीम मास्टर IOIS** - संपूर्ण 1 से 6 क्लास व स्किल का मास्टर एक्सेस

2. **📖 सचित्र NCERT स्टडी नोट्स:**
   - अध्याय-वार सचित्र नोट्स और व्यावहारिक दैनिक जीवन के उदाहरण।
   - **🔊 टेक्स्ट-टू-स्पीच:** छात्र 'बोलकर सुनें' बटन दबाकर पूरा पाठ ऑडियो में सुन सकते हैं।
   - फॉन्ट आकार नियंत्रण (A- / A / A+) और चैप्टर नोट्स डाउनलोड सुविधा।

3. **🎥 आधिकारिक वीडियो कक्षाएं:**
   - Google Flow आधिकारिक वीडियो (`https://flow.google.com/shared/video/52fc05e3-5a11-4930-9a32-34ea84151637`) का शोकेस।
   - विषयवार वीडियो लेक्चर्स, प्लेबैक स्पीड कंट्रोल और वीडियो देखते समय लाइव नोट्स पैड।

4. **🎨 डिजिटल अक्षर व ड्राइंग ट्रेसिंग पैड:**
   - लाइव HTML5 ड्राइंग व ट्रेसिंग कैनवास।
   - डॉटेड गाइड्स: स्वर (अ, आ), व्यंजन (क, ख), गिनती (1, 2, 3), अंग्रेजी (A, B, C), कंप्यूटर फ्लोचार्ट व मैथ्स आरेख।
   - पेंसिल, रबर, विभिन्न रंग, मोटाई और अपने काम को **PNG इमेज में डाउनलोड** करने की सुविधा।

5. **📝 दैनिक गृहकार्य चेकिंग सिस्टम:**
   - प्रत्येक योजना के लिए होमवर्क असाइनमेंट्स, उत्तर सबमिशन और **सत्यापित शिक्षक समीक्षा व स्टार मार्क्स**।

6. **✏️ इंटरएक्टिव अभ्यास व टेस्ट:**
   - वस्तुनिष्ठ प्रश्न (MCQs) तत्काल स्कोरिंग और व्याख्या के साथ।

7. **🪪 डिजिटल छात्र ID कार्ड व सर्टिफिकेट:**
   - डिजिटल छात्र स्मार्ट आईडी कार्ड और पाठ्यक्रम पूरा होने पर आधिकारिक **प्रमाण पत्र (Printable Certificate)**।

## 🚀 GitHub Pages पर लाइव करने के चरण (Deploy to GitHub Pages)

### तरीका 1: GitHub Actions (अनुशंसित - Automatic CI/CD)
इस रिपॉजिटरी में `.github/workflows/deploy.yml` पहले से कॉन्फ़िगर है।

1. अपने टर्मिनल में यह कमांड चलाकर कोड गिटहब पर पुश करें:
```bash
git init
git add .
git commit -m "feat: complete student learning platform with 7 plans, notes, videos, tracing & homework"
git branch -M main
git remote add origin https://github.com/ioisplatform/ioisplatform.github.io.git
git push -u origin main --force
```

2. GitHub रिपॉजिटरी की **Settings** > **Pages** में जाएं।
3. **Build and deployment** > **Source** में **GitHub Actions** चुनें।
4. आपका पोर्टल सीधे **`https://ioisplatform.github.io/`** पर लाइव हो जाएगा!

---

### तरीका 2: लोकल बिल्ड (Manual dist deploy)
```bash
# 1. प्रोडक्शन बिल्ड बनाएं
npm run build

# 2. dist फोल्डर GitHub Pages की gh-pages ब्रांच पर पुश करें
npx gh-pages -d dist
```

## 🛠️ लोकल डेवलपमेंट (Local Run)
```bash
npm install
npm run dev
```
लोकल सर्वर `http://localhost:3000` पर चालू हो जाएगा।
